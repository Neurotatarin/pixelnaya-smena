# Пиксельная смена

Мобильная головоломка: стрелки на конвейере сбивают пиксельные картины.

- Играть в браузере: https://neurotatarin.github.io/pixelnaya-smena/
- iPhone: открой ссылку в Safari, Поделиться, На экран «Домой». Работает как приложение и без интернета.
- Android: APK в разделе Releases (или по ссылке с сайта игры).

Дизайн меняется без кода: PNG и skin.js кладутся в папку `skin/` (см. skin/README.txt). После пуша в main GitHub Actions сам собирает APK и обновляет сайт.
